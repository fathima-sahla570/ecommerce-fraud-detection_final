# 🛡️ E-Commerce Fraud Detection Using Machine Learning

## 📌 Project Overview

E-commerce platforms process thousands of transactions every day. With the rapid growth of online shopping, fraudulent transactions have become a major challenge for businesses.

This project develops an advanced Machine Learning system to detect potentially fraudulent e-commerce transactions by analyzing transaction patterns, customer behavior, transaction velocity, risk-related features, and anomaly patterns.

The project uses **XGBoost** as the main classification model along with feature engineering, SMOTE, model calibration, hyperparameter optimization, and business-cost-based threshold optimization.

---

## 🎯 Objective

The main objectives of this project are:

- Detect fraudulent e-commerce transactions automatically.
- Identify suspicious transaction and customer behavior.
- Handle highly imbalanced fraud data.
- Create meaningful transaction and behavioral features.
- Train and compare Machine Learning models.
- Optimize model hyperparameters.
- Calibrate model probabilities.
- Find an optimal classification threshold based on business cost.
- Evaluate the model using multiple performance metrics.
- Save the trained model and supporting artifacts for future predictions.

---

## 📊 Dataset

This project uses an **E-Commerce / Online Retail transaction dataset** containing historical transaction records.

The dataset includes information related to:

- Transaction details
- Product quantity
- Product price
- Transaction amount
- Customer information
- Transaction date and time
- Country
- Return information
- Customer purchasing behavior

The original dataset is not included in this repository because of its large file size.
